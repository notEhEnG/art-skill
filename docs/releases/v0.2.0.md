# Art Skill v0.2.0

Documentation and verification release with 34 recipes and 52 reviewed examples. Recipe prompts and runtime behavior are unchanged from v0.1.0; the issues below remain unresolved.

## Changes

- Added a [source verification record](../verification-2026-10-25.md) covering recipe content, catalog consistency, installation destinations and saved-plan overwrite protection.
- Documented confirmed recipe-content issues and remaining validation gaps.
- Updated the package version, README download links and pinned installation command for v0.2.0.

## Downloads and installation

- `art-skill-v0.2.0.zip`: the installable `art-skill/` folder with all 34 recipes, references, planner, UI metadata, license and version.
- `SHA256SUMS.txt`: the SHA-256 checksum for that ZIP.
- GitHub's source ZIP and tarball: the full repository, including the 52-example gallery, documentation and project installer.

For Codex, send this in agent chat:

```text
$skill-installer install the art-skill skill from https://github.com/notEhEnG/art-skill/tree/v0.2.0/skills/art-skill
```

For manual project installation, extract the installable ZIP and copy its `art-skill/` folder into `.agents/skills/` for Codex, `.claude/skills/` for Claude Code, or `.cursor/skills/` for Cursor. Preserve or back up existing installations before replacement.

The installable ZIP excludes the gallery. [Browse the examples](../../README.md#gallery) or download the full source archive.

## Verification

- All 14 helper contract tests pass locally. CI runs them on Windows and Linux with Python 3.10 and 3.14.
- ZIP integrity, the 44-file inventory and every archived file are checked against their source bytes. The extracted planner successfully plans the sample brief with each of the 34 recipes without generating images.
- The preceding source review verified an isolated Codex installer run, a project dry-run that creates no directories, and repeated-plan overwrite protection. See the [full record](../verification-2026-10-25.md) for the inspected commit and limits.
- No artwork was regenerated. The v0.1.0 tag and download assets remain unchanged.

## Known issues

- **Scene-specific recipe prompts:** all 12 additional recipes retain composition instructions from their example photographs. The planner includes them even for an unrelated product subject. This is a confirmed prompt-construction issue; a resulting image failure was not measured.
- **Portrait conflicts:** 18 recipes include `real people` in their avoidance lists, which can conflict with requested portraits.
- **Documentation synchronization:** the README and catalog are maintained separately; the shipped tests do not check their synchronization.
- **Photo provenance:** the four original photographs have no supplied author/license metadata establishing redistribution permission. Existing collection documentation records this uncertainty; no permission claim is made.

The passing helper tests do not establish that these recipe-content and provenance issues are resolved.

## Known gaps

- Interactive discovery and live image execution still need smoke tests in each host/version.
- A same-style multi-asset pack, actual cutout transparency and cross-host ZIP/export behavior remain pending.
- Image generation requires an available host image tool; the package does not supply a backend or automatically enable a paid API.
- Installation rollback handles errors and interruptions. Forced process termination or power loss can leave partial files; cleanup failures are reported.

See the [validation record](../validation.md), [roadmap](../../README.md#known-gaps-and-roadmap) and [changelog](../../CHANGELOG.md).
