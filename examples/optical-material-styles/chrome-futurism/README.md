## Practical limits

- A contemporary chrome interpretation, not an art-historical reconstruction or a usable 3D material.
- Palette, fine geometry and cross-image consistency require visual review; generation is not deterministic.
- Some very bright highlights lose local surface detail; reflection geometry is invented.
