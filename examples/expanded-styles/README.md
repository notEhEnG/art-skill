## Recorded run

Twelve built-in image calls produced twelve saved native PNGs, with zero repairs or observed moderation blocks. The maximum call budget was fifteen. Actual dimensions, hashes, final prompts, frozen recipes and review notes are recorded per image. Some fine detail and palette interpretations differ from the recipe; those limitations are listed on each page. Model identity and monetary cost were not exposed.

Every example uses its original photo directly, with no mixed scenes or derivative input chain. Single examples demonstrate an aesthetic, not guaranteed consistency across a future pack. These are raster visuals rather than print plates, vector paths, 3D models or fabrication files.
