## Practical limits

- This is an image aesthetic, not a real photographic exposure or calibrated cyanotype process.
- Palette and fine geometry are prompt guidance and require visual review across a series.
- The rendering includes irregular pale paper edges and photographic fine detail; it is not an actual exposure process.
