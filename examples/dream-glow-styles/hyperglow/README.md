## Practical limits

- A raster light effect; no HDR luminance, emissive material, animation or calibrated spectral behavior is provided.
- Palette, fine geometry and cross-image consistency require visual review; generation is not deterministic.
- Fine cloud detail remains visible, so this is a glowing cloud reinterpretation rather than a completely abstract gradient field.
