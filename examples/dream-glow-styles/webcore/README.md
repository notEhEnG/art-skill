Native PNG: 1112 × 1415. 1 built-in image call(s); 0 repairs. Model identity and monetary cost were not exposed.

## Practical limits

- A static bitmap aesthetic; it is not a functional website, UI implementation, exact pixel grid or guaranteed readable text.
- Palette, fine geometry and cross-image consistency require visual review; generation is not deterministic.
- Decorative wireframe arcs are added above the source scene and the image does not obey an exact pixel grid.
